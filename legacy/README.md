# legacy/

Original prototype files, kept for provenance. Nothing here is evidence for the EGGA project;
results come only from `src/egga/` and `results/`. Files below were moved with `git mv` and are
unedited, except the ones listed as "added".

| File | What it actually does |
|---|---|
| `mission_proving_ground_rl.m` | 75 s, 5-stage mission on a 2-DOF bicycle (10 m/s, no delay or noise). Runs PID, a fixed PD+feedforward labelled "MPC", and the RL scheduler. Plot legends hard-code 18.4 / 6.1 / <1.85 cm; those are typed text, not outputs. |
| `rl_adaptive_controller.m` | 6-8-4 tanh MLP (92 parameters) with **hand-typed** weights, followed by hand rules (friction and slope multipliers) and clipping. Takes ground-truth mu and slope. |
| `exported_rl_weights.m` | Weights exported from `train_rl_agent.py`. Not used by any benchmark script. |
| `train_rl_agent.py` | Actor loss is MSE(actor(s), executed action) x mean(advantage), not a policy gradient. One seed, 150 episodes. |
| `generate_missing_benchmarks.py` | Step-response and "safety ablation" plots with hard-coded absolute paths. The ablation figure draws violation counts from random numbers. |
| `synthetic_do_not_cite/Figure_Training_Safety_Ablation.png` | The synthetic "Figure 6". Unconstrained violations are random draws and the constrained curve is hard-coded to 0. Do not cite. |
| `master_bicycle_simulation.m` | Contains the only real condensed MPC (Np=15, Nc=5); not part of the benchmark. |
| `BicyclePathTracking1.slx`, `run_in_simulink.m` | Linear bicycle with a fixed steering PID. No RL, no MPC. |
| `RL_PID_Controller_Project.docx` | Original proposal. Its wording "provably stable" is not supported by any code in the repo. |
| `ORIGINAL_README.md` | Original README, superseded by the root `README.md`. Contains unsupported claims. |
| `Figure_Lateral_Tracking_Benchmark.jpeg`, `Figure_Step_Response_Benchmark.png` | Original figures, not regenerated by this repo. |
| `lib3.py`, `t_lqr.py` (added) | The audit's Python port and LQR experiment. Used only as a cross-reference; see `docs/phase0_discrepancies.md` and `tools/check_lib3_delay_offset.py`. |
